# Inadimplência BRASAS

Script Google Apps Script da planilha "Títulos vencidos - 2026".

Instalação: planilha > Extensões > Apps Script > colar `Codigo_Financeiro_BRASAS.gs` > salvar > recarregar a planilha.
Ordem: Configuração > Preparar aba Config, depois "1. Atualizar tudo agora".

Não versionar aqui planilhas, prévias com nomes de alunos ou qualquer dado financeiro.
